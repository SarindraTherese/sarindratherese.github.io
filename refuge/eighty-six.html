86 — EIGHTY-SIXQui est qui ?

41 personnages, avec portrait, écriture japonaise et un repère court. Les sections suivantes restent repliées tant qu’on n’y est pas.

Astuce pour le novel : chaque pilote porte un Personal Name, son nom de code au combat — Shin est Undertaker. Les traductions transcrivent aussi les noms différemment : Nouzen / Nōzen / Nozen, Milizé / Milize. La recherche accepte toutes les variantes affichées sur les fiches.
🛡️ Protection anti-spoil : ni les évolutions, ni les changements d’affectation, ni les relations futures, ni les issues de combat ne sont indiqués. Même les personnages les plus connus ne sont décrits que tels qu’ils apparaissent.
